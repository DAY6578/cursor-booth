# チャンネル（ファンコミュニティ）

チャンネルは10個です。カテゴリを先に作り、その中へチャンネルを入れます。権限の操作は `../common/02-roles-and-permissions.md` です。

拒否は `@everyone` だけに付けます。

## 一覧

| カテゴリ | チャンネル | 種類 | 用途 |
| --- | --- | --- | --- |
| 案内 | ルール | テキスト | ルールの掲示。参加者は読むだけ |
| 案内 | お知らせ | テキスト | 運営からの連絡。参加者は読むだけ |
| 案内 | 自己紹介 | テキスト | 参加後に指定の型で1回書く |
| 交流 | 雑談 | テキスト | ふだんの会話 |
| 交流 | 作品と配信 | テキスト | 自分の作品、配信の告知 |
| 交流 | コラボ募集 | テキスト | 一緒にやる人の募集 |
| 交流 | 質問 | テキスト | サーバーの使い方と、活動への質問 |
| ボイス | 雑談 | ボイス | 声の会話 |
| ボイス | 作業 | ボイス | 一緒に作業する。雑談より静かにする |
| 運営 | 運営メモ | テキスト | 対応記録。参加者には見せない |

## 見てよい人、書いてよい人

「見る」「送る」はテキストです。ボイスは「見る」「接続」「発言」です。

| チャンネル | @everyone | メンバー | モデレーターと管理者 |
| --- | --- | --- | --- |
| ルール | 見る許可、送る拒否 | 見る許可、送る拒否 | 見る許可、送る許可 |
| お知らせ | 見る許可、送る拒否 | 見る許可、送る拒否 | 見る許可、送る許可 |
| 自己紹介 | 見る許可、送る許可 | 見る許可、送る許可 | 見る許可、送る許可 |
| 雑談 | 見る拒否 | 見る許可、送る許可、ファイル許可、埋め込み許可、リアクション許可 | 同じ許可に加え、メッセージの管理はロール権限で可 |
| 作品と配信 | 見る拒否 | 雑談と同じ | 雑談と同じ |
| コラボ募集 | 見る拒否 | 雑談と同じ | 雑談と同じ |
| 質問 | 見る拒否 | 雑談と同じ | 雑談と同じ |
| 雑談（ボイス） | 見る拒否、接続拒否 | 見る許可、接続許可、発言許可 | 見る許可、接続許可、発言許可、メンバーの移動とミュートはロール権限で可 |
| 作業（ボイス） | 見る拒否、接続拒否 | 見る許可、接続許可、発言許可 | 雑談ボイスと同じ |
| 運営メモ | 見る拒否 | 上書きなし | 見る許可、送る許可 |

お知らせ通知ロールは、チャンネル権限を変えません。お知らせを配るとき、運営がそのロールをメンションします。

「上書きなし」は、そのロールに緑も赤も付けない、という意味です。運営メモは `@everyone` の拒否だけにして、メンバーには赤を付けません。モデレーターにメンバーを重ねて付けても、赤が勝って運営メモが見えなくなる事故を避けます。

自己紹介だけ、ロールが無い人にも送信を許可します。ここに型どおり書いた人へ、メンバーを付けます。ほかの交流チャンネルは、メンバーが付くまで見えません。

## トピックに入れる1行

| チャンネル | トピック |
| --- | --- |
| ルール | 参加前に読んでください。このチャンネルには書き込めません。 |
| お知らせ | 運営からの連絡だけを書きます。 |
| 自己紹介 | 固定してある型を、1人1回書いてください。 |
| 雑談 | ルールの範囲で、自由に話してよいチャンネルです。 |
| 作品と配信 | 自分の作品と配信の告知です。他人の作品の転載は、許可があるときだけにしてください。 |
| コラボ募集 | 一緒に活動する人を募る場所です。営業だけの投稿は、先に運営へ聞いてください。 |
| 質問 | サーバーの使い方と、活動への質問です。 |
| 運営メモ | 対応の記録です。外へコピーしません。 |

## ピン留め

| チャンネル | ピン留めするもの |
| --- | --- |
| ルール | ルール文を1件 |
| お知らせ | 歓迎文を1件。古い案内はピンを外す |
| 自己紹介 | 自己紹介の型を1件 |

ピンは増やしすぎないでください。新しい案内をピンするときは、古いピンを外します。

## 作る順番

1. カテゴリ「案内」「交流」「ボイス」「運営」を作る。
2. 上の表のチャンネルを、そのカテゴリの中に作る。
3. 案内カテゴリで、`@everyone` の送信を拒否し、見ることは許可する。自己紹介だけ送信を許可し直す。
4. 交流カテゴリとボイスカテゴリで、`@everyone` の見るを拒否する。メンバーに見る、送る、接続、発言を許可する。
5. 運営カテゴリで、`@everyone` の見るを拒否する。メンバーには赤を付けない。モデレーターと管理者に見ると送るを許可する。
6. テスト用アカウントで、ロール無し、メンバー有り、の2状態を見る。
