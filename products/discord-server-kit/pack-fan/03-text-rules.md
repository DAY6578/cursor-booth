# ルール文（ファンコミュニティ）

`ルール` チャンネルに、この枠を1件貼ってピン留めします。【　】だけを変えます。条項を足すときは、番号を続けてください。法律の助言ではありません。

```
【コミュニティ名】のルール

このサーバーは、【コミュニティ名】の参加者同士が話す場所です。権利者の公式サーバーではありません。

1. Discordの利用規約と、住んでいる地域の法律に従ってください。
2. 誹謗中傷、差別、嫌がらせ、性的な嫌がらせをしないでください。
3. 自分と他人の個人情報を書かないでください。本名の強制公開、住所、電話番号、通っている学校や職場、口座、パスワードは禁止です。
4. 他人の作品、配信、文章を、許可なく貼らないでください。自分の作品の告知は「作品と配信」でできます。
5. 営業、勧誘、このサーバーと無関係な宣伝は、先に運営へ聞いてください。
6. ネタバレを書くときは、作品名を先に書き、本文は折りたたみか、相手の同意があるときだけにしてください。
7. 運営の注意に従ってください。繰り返す場合は、注意、タイムアウト、キック、参加禁止の順で対応します。
8. ルールの抜け道になる頼み方は、ルール違反と同じに扱います。

運営への連絡は、公開の会話を止めたいときに「質問」チャンネルで「運営へ」と書いてください。個人情報を含む相談は、そこに書かず、運営の表示名へダイレクトメッセージで「相談がある」とだけ送ってください。本文は、運営が案内した場所で聞きます。

この文章は運営のためのたたき台であり、法律の助言ではありません。
```

## 貼ったあとの確認

- [ ] 【コミュニティ名】が残っていない
- [ ] 連絡先のメールアドレスや電話番号を足していない
- [ ] 「公式」「公認」と書いていない
- [ ] ピン留めがこの1件である
