# 参加確認（ボット無し）

メンバーロールは、人が確認して手で付けます。ボットの招待、外部サイトへの登録、有料の会員機能は使いません。

やり方は次のどちらか1つに決めてください。両方を重ねてもかまいません。

## A. Discord標準のルール同意を使う

コミュニティ機能を有効にできるときだけです。手順の場所は `../common/01-server-setup.md` にあります。

- [ ] ルールチャンネルに、ルール文がピン留めされている
- [ ] ルール同意がオンである
- [ ] テスト用アカウントで、同意の前は交流チャンネルに書けない
- [ ] 同意のあと、自己紹介には書ける
- [ ] 自己紹介の確認後に、メンバーを手で付ける
- [ ] メンバーが付くと、交流とボイスが見える

メニューが無い場合は、Bへ進みます。Aが無くても公開できます。

## B. 自己紹介を見て手で付ける

ボットもコミュニティ機能も使いません。チャンネル権限は `01-channels.md` のままで動きます。

参加した人ごとに、上から確認します。

- [ ] 自己紹介が1件ある
- [ ] 呼び名、好きなこと、このサーバーでしたいこと、が書かれている
- [ ] ルールを読んだことが文面から分かる。分からなければ「ルールを読んだら、その旨を自己紹介に1行足してください」と返す
- [ ] 個人情報が無い
- [ ] 宣伝だけ、または空の投稿ではない
- [ ] 問題がなければメンバーを付ける
- [ ] お知らせ希望が「希望する」のときだけ、お知らせ通知を付ける
- [ ] 返信例の短文を1回返す

目安は、見てから24時間以内です。遅れるときは、お知らせに「確認が遅れています」と1行だけ書きます。

保留にする例:

- 項目が空
- 他サーバーへの招待だけが書いてある
- ルールの確認が取れない

保留の人にメンバーは付けません。自己紹介以外は見えないままです。

## 外すとき

メンバーを外すのは、キックやBANの前段です。共通の初動で注意やタイムアウトが先です。ロールを外すだけで黙って終わらせず、運営メモに理由の要約を残します。
