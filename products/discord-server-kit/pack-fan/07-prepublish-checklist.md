# 公開前チェック（ファンコミュニティ）

すべてに印が付いてから、招待リンクを配ります。

## ロール

- [ ] 並びが、管理者、モデレーター、お知らせ通知、メンバー、@everyone の順である
- [ ] どのロールにも「管理者」権限が付いていない
- [ ] モデレーターに、BAN、チャンネルの管理、ロールの管理が付いていない
- [ ] お知らせ通知は、メンション許可以外の権限が増えていない

## チャンネル

- [ ] 10個ある。ルール、お知らせ、自己紹介、雑談、作品と配信、コラボ募集、質問、雑談ボイス、作業ボイス、運営メモ
- [ ] ロールが無いテスト用アカウントには、ルール、お知らせ、自己紹介だけが見える
- [ ] そのアカウントは、自己紹介以外に書けない
- [ ] メンバーを付けると、交流4チャンネルとボイス2つが使える
- [ ] 運営メモは、モデレーターと管理者以外から見えない
- [ ] ルール、歓迎、自己紹介の型が、それぞれのチャンネルにピン留めされている
- [ ] 文面の【　】が残っていない

## 安全

- [ ] サーバー名とアイコンに、他社ロゴと「公式」「公認」が無い
- [ ] 招待は期限と回数が付いている。無期限のリンクを、公開前に配っていない
- [ ] モデレーションの初動を、運営が読んだ
- [ ] バックアップと引き継ぎのチェックを、所有者が読んだ
- [ ] テンプレートを作る場合は、生成と保管が終わっている。メニューが無い場合は、チャンネル表とロール表を手元に写した

## 配るとき

- [ ] 招待を渡す相手が、このサーバーの参加者として想定した人である
- [ ] 配った日付と、期限を運営メモに書いた。リンクの全文は書かない
