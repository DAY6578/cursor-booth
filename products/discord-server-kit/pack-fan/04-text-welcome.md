# 歓迎文（ファンコミュニティ）

`お知らせ` チャンネルに貼り、ピン留めします。新しい人向けの入口は、この1件にまとめます。

```
【コミュニティ名】へようこそ。

このサーバーは、参加者同士の交流場所です。公式の窓口ではありません。

最初に読む場所
1. 「ルール」を読む
2. 「自己紹介」に、固定してある型を1回書く
3. 運営がメンバーロールを付けたら、「雑談」「作品と配信」「コラボ募集」「質問」と、ボイスチャンネルが使えます

お知らせを受け取りたい人は、自己紹介に「お知らせ希望」と書いてください。希望した人だけに、お知らせ通知ロールを付けます。

やってはいけないことの詳細は、ルールに書いてあります。
個人の連絡先は、このチャンネルに書かないでください。
```

ルール同意の画面（コミュニティ機能）を使う場合は、次の1行を歓迎文の末尾に足します。

```
参加時にルール同意が出ます。同意するまで、チャンネルへの投稿はできません。
```

コミュニティ機能を使わない場合は、この1行を足しません。参加確認は `06-membership-checklist.md` の手動手順です。
