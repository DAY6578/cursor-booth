# 自己紹介の文面（ファンコミュニティ）

`自己紹介` チャンネルに、この型を貼ってピン留めします。参加者には、同じ項目を1回書いてもらいます。

ピン留め用:

```
自己紹介は、この型で1人1回書いてください。書いたあとに、運営がメンバーロールを付けます。

呼び名:
好きなこと:
このサーバーでしたいこと:
お知らせ希望: 希望する / 希望しない
作品や配信の場所（任意）:

本名、住所、電話番号、学校名、職場名は書かないでください。
```

## 運営が見る点

- 3つの必須項目（呼び名、好きなこと、このサーバーでしたいこと）が空でない
- 個人情報らしいものが無い。あったら、共通の初動に従って削除する
- 宣伝だけの文面なら、メンバーを付ける前に、ルール5番を短く伝えて書き直しを頼む
- 「お知らせ希望: 希望する」の人にだけ、お知らせ通知を付ける

返信の例:

```
確認しました。メンバーロールを付けました。交流チャンネルが使えます。
```
