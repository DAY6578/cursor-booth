# Discordサーバー設計・運用キット

`はじめての人へ.html` をダブルクリックすると、ブラウザで手順が開きます。ネットも、ボットも、不要です。メモ帳で開いたときは、右クリックしてブラウザで開いてください。

ファンコミュニティ用と、大会・カスタムマッチ主催用を、1つのキットにまとめています。

## まずやること

1. `はじめての人へ.html` を開く。
2. 用途を1つ選ぶ。
   - 配信者や創作者のファンコミュニティ
   - 大会やカスタムマッチの主催
3. 画面の番号どおりに進める。各手順には、押す場所、作る名前、コピー、できた状態が書いてあります。
4. 文面の【　】を、自分のサーバーの言葉に置き換えてから貼る。
5. 最後のチェックリストが終わるまで、招待リンクを配らない。

選んだ用途だけ進めれば足ります。もう一方は使わなくてかまいません。

同じサーバーで両方使う場合も、先に画面のロールの並びを決めてください。ロール名が重なったら、権限が強い方の名前を上に置きます。

## フォルダ

| ファイル | 中身 |
| --- | --- |
| `はじめての人へ.html` | 最初に開く手順画面 |
| `common/` | 詳細。作り方、権限、初動、命名、バックアップ |
| `pack-fan/` | 詳細。ファンコミュニティの表と文面 |
| `pack-event/` | 詳細。大会・カスタムの表、当日手順、トラブル対応 |

各パックの `role-cards/` は、ルールチャンネルに貼るための役割カードです。使わなくてもサーバーは作れます。ゲームのロゴや、他社の絵は入っていません。

## 画面の名前が違うとき

Discordのメニュー名は、更新で変わることがあります。

手順は、一般的な画面名で書いてあります。同じ名前が無いときは、同じ意味の項目を探してください。テンプレート機能が無くても、手順画面だけで作れます。細かい表は `common/` と各パックに残してあります。

## サーバーテンプレート

チャンネルとロールを作り終えたあと、Discord標準のサーバーテンプレートで骨組みをコピーできます。手順の詳細は `common/01-server-setup.md` です。公開前チェックで、作るか手元に写すかを選びます。

テンプレートに入るのは、チャンネル、ロール、権限などの骨組みです。メッセージ、ピン留め、メンバー、参加禁止の一覧は入りません。

## このキットに無いもの

- ボット、およびボットの招待手順
- 配信画面用の枠や時計
- 特定のゲームの公式ルール、公式ロゴ、公式素材
- 弁護士の確認を受けた利用規約

ルール文は、運営が手を入れるためのたたき台です。法律の助言ではありません。

## 詳細を読むとき

画面の手順で足りるときは、ここを読みません。

1. `common/01-server-setup.md`
2. `common/02-roles-and-permissions.md`
3. `common/03-moderation-first-response.md`
4. `common/04-naming-rules.md`
5. `common/05-backup-and-handoff.md`
6. 選んだパックの `README.md` から番号順

招待の前に、パックの公開前チェックリスト（画面の最後の手順と同じ項目）を通してください。モデレーションの初動とバックアップは、そのチェックの中で読みます。

## 利用範囲

- 自分のDiscordサーバーの設計と運営に使ってよい
- 文面を、そのサーバー向けに書き換えてよい

次のことはしないでください。

- このキットのファイルの再配布、転売
- このキットを部品にした再販売
