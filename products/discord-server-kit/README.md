# Discordサーバー設計・運用キット

ファンコミュニティ用と、大会・カスタムマッチ主催用を、1つのキットにまとめた文書です。

ボットの導入、配信用の素材、有料サービスの契約は不要です。Discordの標準機能と、この文書の表・文面・チェックリストだけでサーバーを作れます。

## まずやること

1. この説明を読む。
2. `common/` を、ファイル名の番号順に読む。
3. 用途を1つ選ぶ。
   - 配信者や創作者のファンコミュニティ → `pack-fan/`
   - 大会やカスタムマッチの主催 → `pack-event/`
4. 選んだパックを、ファイル名の番号順に進める。
5. 文面の【　】を、自分のサーバーの言葉に置き換えてから貼る。
6. パックのチェックリストが終わるまで、招待リンクを配らない。

共通を読んだあとなら、パックはどちらか一方だけで使えます。もう一方は読まなくてかまいません。

同じサーバーで両方使う場合も、先に共通のロールの並びと権限の考え方を決めてください。ロール名が重なったら、権限が強い方の名前を上に置きます。

## フォルダ

| フォルダ | 中身 |
| --- | --- |
| `common/` | サーバーの作り方、ロールと権限、モデレーションの初動、命名、バックアップと引き継ぎ |
| `pack-fan/` | ファンコミュニティのチャンネル、ロール、ルール、歓迎、自己紹介、参加確認、公開前チェック |
| `pack-event/` | 大会・カスタムのチャンネル、ロール、ルール、受付、日程、欠席、当日手順、トラブル対応 |

各パックの `role-cards/` は、ルールチャンネルに貼るための役割カードです。使わなくてもサーバーは作れます。ゲームのロゴや、他社の絵は入っていません。

## 画面の名前が違うとき

Discordのメニュー名は、更新で変わることがあります。

このキットの手順は、一般的な画面名で書いてあります。同じ名前が無いときは、各ファイルの「見つからないとき」に従って、同じ状態を手で作ってください。テンプレート機能が無くても、表とチェックリストだけで作れます。

## サーバーテンプレート

チャンネルとロールを作り終えたあと、Discord標準のサーバーテンプレートで骨組みをコピーできます。手順は `common/01-server-setup.md` です。

テンプレートに入るのは、チャンネル、ロール、権限などの骨組みです。メッセージ、ピン留め、メンバー、参加禁止の一覧は入りません。

## このキットに無いもの

- ボット、およびボットの招待手順
- 配信画面用の枠や時計
- 特定のゲームの公式ルール、公式ロゴ、公式素材
- 弁護士の確認を受けた利用規約

ルール文は、運営が手を入れるためのたたき台です。法律の助言ではありません。

## 利用範囲

- 自分のDiscordサーバーの設計と運営に使ってよい
- 文面を、そのサーバー向けに書き換えてよい

次のことはしないでください。

- このキットのファイルの再配布、転売
- このキットを部品にした再販売
