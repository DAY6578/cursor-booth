# トラブル時の手順

当日に判断が割れやすいものを、先に決めておきます。人への対応の基本は `../common/03-moderation-first-response.md` です。こちらは大会の進行用です。

スタッフ連絡に、このファイルの場所を1行で固定しておきます。公開チャンネルへ、この手順の全文は貼りません。

## 接続できない

1. その人を待機ボイスに戻す。テキストなら試合連絡で「待機に戻ってください」と書く。
2. 5分待つ。ほかの試合が止められるなら、次の組を先にしない。
3. 同じ人が2回続けて接続できないときは、その試合を後ろへ移すか、不戦にする。主催がどちらかを一つ選ぶ。
4. 結果には「中断」または「不戦」と、表示名だけを書く。回線の事情の詳細は書かない。

## 選手が来ない

1. 欠席連絡を見る。
2. 連絡が無く、呼び出しから10分経っても待機にいないときは、不戦とする。
3. 待機ロールの補欠がいれば、主催の同意で選手に付け替える。
4. 結果の型で「不戦」と書く。

待ち時間を変える大会は、ルール文の【分】を変えます。当日だけ口頭で変えないでください。変えるなら日程ピンを更新します。

## 暴言、妨害、嫌がらせ

1. 試合を止める。
2. 共通の初動に従い、公開の短文を1回だけ貼る。
3. 必要ならタイムアウトにする。
4. 続行できる状態なら再開する。できないなら、その試合は中断とし、主催が不戦か延期かを一つ決める。
5. BANが必要なら主催だけが行う。

## 結果が食い違う

1. 双方の言い分を、スタッフ連絡へ2行以内で要約する。スクリーンショットを公開チャンネルへ貼らない。
2. 主催が、どちらか一つを選ぶ。選びようが無いときは、その試合を中断とし、ルールの細則に再試合の有無を追記してから日程を更新する。
3. 決めた文を、結果チャンネルへ通常の型で書く。
4. 決めたあとも異議が続く場合は、ルールの時間内ならもう一度だけ受け、時間外なら次の試合を優先する。

## 個人情報やアカウント情報が見えた

1. 配信をしているなら、止めるよう配信者に伝える。
2. チャットに書いてあれば、すぐ削除する。
3. 番号、住所、パスワードを、スタッフ連絡にも書き写さない。「個人情報を削除した」とだけ残す。
4. 故意なら、主催がBANを判断する。

## なりすまし

1. その人の選手、待機、観戦を外す。
2. 試合ボイスにいれば移動して退出させる。
3. なりすまされた側の表示名を、スタッフ連絡で確認する。
4. 主催がBANを判断する。結果に影響した試合は「中断」とし、再試合をするかを主催が決める。

## 中止

続行できないとき、主催が大会告知に、次の短文だけを貼ります。

```
【大会名】は、【日付】の進行を中止します。
理由の区分: 接続の障害 / 運営の不足 / 安全上の理由 / その他
再開: する（日程を更新します） / しない
```

賞品や参加費の扱いは、告知に書いてあった方法に従います。このキットのなかでは、返金先や口座を聞きません。新しい支払い先を、中止文に足さないでください。

## 記録

トラブル1件につき、スタッフ連絡へこの型を1つ残します。

```
時刻:
区分: 接続 / 不参 / 暴言 / 結果 / 個人情報 / なりすまし / 中止
対象の表示名:
決めたこと:
決めた人:
結果チャンネルへ書いたか: 書いた / 書いていない
```
