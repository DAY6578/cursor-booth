# 欠席・遅刻の文面

`欠席連絡` に、この型をピン留めします。

```
欠席、遅刻、早退は、この型で1件書いてください。
開始の【分】前までに書いてください。それより遅い連絡は、当日手順どおりに不戦や途中交代を判断します。

チーム名（個人参加なら「個人」）:
表示名:
区分: 欠席 / 遅刻 / 早退
到着または離席の目安（日本時間）:
代わりに出られる表示名（いない場合は「なし」）:

理由の詳細、住所、体調の診断名は書かないでください。一言で足ります。
```

## スタッフの扱い

| 区分 | やること |
| --- | --- |
| 欠席 | 選手または待機を外す。定員に空きが出たことを、スタッフ連絡に残す。必要なら次の待機を選手に変える |
| 遅刻 | 待機ボイスへ入ってもらう。試合の呼び出し時刻に間に合わなければ、当日手順の不戦に進む |
| 早退 | 残りの試合に出ないことを結果のメモに残す。ロールは、その日の終了まで選手のままか、外すかをスタッフ連絡で決める |

欠席の文面を、結果チャンネルへそのまま転記しません。結果に書くのは「不戦」または「交代」と、表示名だけです。
