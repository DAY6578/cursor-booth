# ルール文（大会・カスタム）

`ルール` チャンネルに貼ってピン留めします。【　】を置き換えてください。ゲーム固有の勝ち負けは、末尾の空欄に主催が書きます。このキットは、特定タイトルの公式ルールではありません。

```
【大会名】のルール

このサーバーは、【大会名】の連絡場所です。ゲームの権利者の公式大会ではありません。

1. Discordの利用規約と、住んでいる地域の法律に従ってください。
2. 主催とスタッフの進行に従ってください。呼び出しに返事が無い場合は、当日手順の待ち時間で判断します。
3. 誹謗中傷、差別、嫌がらせ、試合の妨害をしないでください。
4. 個人情報を書かないでください。本名の強制、住所、電話番号、パスワード、部屋が映る画像は禁止です。
5. 不正なツール、なりすまし、他人のアカウントの利用は、参加禁止にします。
6. 結果は、スタッフが「結果」チャンネルに書いたものを正とします。異議は、その投稿から【分】以内に「試合連絡」へ書いてください。時間を過ぎた異議は、次の試合を止めません。
7. 欠席、遅刻、早退は、「欠席連絡」の型で、開始【分】前までに書いてください。
8. 配信と録画の可否は、告知に書いたほうに従ってください。選手の声や画面を、許可なく切り抜いて公開しないでください。
9. 賞品や参加費がある場合は、告知に書いた方法だけが有効です。このサーバーの会話のなかで、個別の支払い先を聞きません。

【ゲーム名】で主催が足す細則:
- 
- 

この文章は運営のためのたたき台であり、法律の助言ではありません。
```

細則が無いときは、箇条書きに「今回は追加の細則はありません」と書いて、空欄のままにしないでください。
