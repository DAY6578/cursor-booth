# 当日の手順

スタッフが、上から順に印を付けます。時刻は、日程ピンの試合開始を基準にします。

## 前日まで

- [ ] ルール、日程、参加受付、欠席のピンが、それぞれ1件である
- [ ] 参加受付の送信を、締切後に拒否へ変えた
- [ ] 選手、待機、観戦の人数を、スタッフ連絡に表示名で書いた
- [ ] 試合ボイスの画面共有がオフである。使う場合だけ、主催が許可範囲をスタッフ連絡に書いた
- [ ] 結果チャンネルに、まだ空の結果が無い。書き始めの1件だけ、下の見出しを置いてよい

結果の見出し例:

```
【大会名】の結果
このチャンネルの結果投稿を正とします。異議はルールの時間内に、試合連絡へ書いてください。
```

## 開始90分前

- [ ] スタッフがサーバーにいる
- [ ] 待機、試合、観戦の権限を、ロール無しのアカウントで再確認した
- [ ] 欠席連絡を読み、外すロールを外した

## 開始30分前

- [ ] 待機ボイスが接続できることを、スタッフの一人が確認した
- [ ] 試合連絡に、最初の呼び出し順を書いた。表示名とチーム名だけにする

呼び出しの型:

```
次の試合
チームまたは表示名:
チームまたは表示名:
待機ボイスに入ってください。開始【分】前に、試合ボイスへ移動します。
```

## 開始10分前

- [ ] 呼び出された人が待機にいる
- [ ] いない人は、欠席連絡を確認する。無ければ、トラブル手順の「来ない」に進む
- [ ] 観戦希望の人が、観戦ボイスに入れる

## 開始

- [ ] スタッフが、出場する人を試合ボイスへ移動する。移動権限が無いときは、呼び出し文で移動を頼む
- [ ] 待機ロールのままの人は、試合ボイスに入っていない
- [ ] 観戦は観戦ボイスにいる。試合ボイスの発言権限が無い

## 試合中

- [ ] 結果の争いは、その場で長引かせない。一度止めて、異議の時間に回す
- [ ] 暴言や妨害は、共通の初動に切り替える。試合は止める
- [ ] 1試合が終わるたびに、結果チャンネルへ1件書く

結果の型:

```
試合番号:
対戦:
勝者:
敗退:
区分: 通常 / 不戦 / 中断
記録した人:
```

## 終了後30分

- [ ] 最後の結果がピンではなく、通常の投稿として時系列に残っている。ピンは見出しだけ
- [ ] 試合ボイスを空にした
- [ ] 画面共有を許可していたら、オフに戻した
- [ ] 異議の受付を閉じる時刻を、結果の見出しへ追記した
- [ ] 一時的に増やしたチームチャンネルが無い。あるなら、テンプレート同期の前に削除する予定をスタッフ連絡へ書いた

翌日以降に、共通のバックアップ手順で、必要な文面だけを手元へ残します。会話の全文を書き写す必要はありません。
