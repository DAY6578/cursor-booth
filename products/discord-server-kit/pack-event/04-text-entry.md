# 参加受付の文面

`参加受付` のピン留めに、この枠を貼ります。参加者は、同じ項目を1件書いてください。メールアドレスや電話番号の欄は足しません。

```
【大会名】の参加受付

ゲーム: 【ゲーム名】
日時: 【日付】 【時刻】（日本時間）
定員: 【人数】
受付締切: 【日付】 【時刻】
参加条件: ルールチャンネルを読んでいること

この型を、1チームまたは1人につき1件書いてください。

チーム名（個人参加なら「個人」）:
代表の表示名:
参加者の表示名:
人数:
ゲーム内の表示名:
連絡が取れる時間帯:
観戦だけ希望: する / しない

ファイルの添付はできません。
本名、住所、電話番号、メールアドレスは書かないでください。
締切後の追加は、スタッフの表示名へ「受付の追加がある」とだけ送ってください。条件はスタッフが返します。
```

## スタッフの確認

1件ごとに、次を見てからロールを付けます。

- [ ] 必須の行が空でない
- [ ] 個人情報らしいものが無い。あれば削除し、書き直しを頼む。内容は運営メモに写さない
- [ ] 定員を超えていない。超える分は待機にするか、受付終了を告知する
- [ ] 観戦だけ希望が「する」なら、観戦だけを付ける。選手は付けない
- [ ] 出場させるなら選手、補欠や未確定なら待機
- [ ] スタッフ連絡に、表示名と付けたロールだけを1行で残す

返信例:

```
受付を確認しました。ロールを付けました。日程チャンネルのピンを確認してください。
```
