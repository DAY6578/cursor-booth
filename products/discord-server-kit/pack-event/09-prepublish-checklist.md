# 公開前チェック（大会・カスタムマッチ）

すべてに印が付いてから、招待リンクを配ります。

## ロール

- [ ] 並びが、管理者、スタッフ、選手、待機、観戦、@everyone の順である（名前は自分の鯖に合わせてよい）
- [ ] どのロールにも「管理者」権限が付いていない
- [ ] スタッフに、BAN、チャンネルの管理、ロールの管理が付いていない（必要な権限だけ）
- [ ] 拒否の上書きは `@everyone` だけである。選手・待機・観戦に赤を付けていない

## チャンネル

- [ ] テキスト9個、ボイス3個ある（大会告知、ルール、日程、参加受付、チーム連絡、欠席連絡、試合連絡、結果、スタッフ連絡／待機・試合・観戦ボイス）
- [ ] ロールが無いテスト用アカウントには、案内（告知・ルール・日程）と参加受付だけが見える
- [ ] そのアカウントは、参加受付以外に書けない
- [ ] 選手を付けると、チーム連絡・欠席・試合連絡・結果・待機／試合ボイスが使える
- [ ] 観戦を付けると、結果と観戦ボイスが使える
- [ ] スタッフ連絡は、スタッフと管理者以外から見えない
- [ ] ルール、受付、日程、欠席の型が、それぞれのチャンネルにピン留めされている
- [ ] 文面の【　】が残っていない

## 受付の開閉

- [ ] 受付を閉じるときは、参加受付の `@everyone` の送信だけを拒否にする（見るは残す）
- [ ] 選手や待機には、送信拒否を付けていない
- [ ] 次の大会で開く手順（`@everyone` の送信を許可に戻す）をスタッフが知っている
