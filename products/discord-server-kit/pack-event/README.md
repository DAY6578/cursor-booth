# 大会・カスタム主催パック

対戦ゲームのカスタムマッチや、小規模な大会を、1つのDiscordで回すための文書です。特定のゲームの公式ルールやロゴは入っていません。ゲーム名は、主催が【ゲーム名】へ入れます。

ファンコミュニティパックは読みません。

初心者は先に `../はじめての人へ.html` を開く。このフォルダの番号ファイルは詳細です。

画面の手順だけでサーバーを作れます。表の細かい条件を確認したいときだけ、このフォルダを番号順に読んでください。最後の確認項目は `09-prepublish-checklist.md` です。

## このパックで作るもの

- テキスト 9個、ボイス 3個
- ロール 5つ。主催、スタッフ、選手、待機、観戦
- ルール、参加受付、日程、欠席の文面
- 当日の手順
- トラブル時の手順
- 公開前チェック

`role-cards/` の画像は3枚です。主催、スタッフ、選手の説明用です。貼らなくても進行できます。

## 進め方

1. `02-roles.md` のロールを作る。
2. `01-channels.md` のチャンネルと権限を作る。
3. `03-text-rules.md` から `06-text-absence.md` の枠を貼る。
4. 参加者が書き込む前に、`07-day-of-runbook.md` をスタッフと読む。
5. `08-incident.md` の置き場所を、スタッフ連絡に固定する。
6. 招待の前に、`../common/03-moderation-first-response.md` と `../common/05-backup-and-handoff.md` を主催が読む。
7. `09-prepublish-checklist.md` をすべて通してから、招待リンクを配る。

このパックは決済、賞品の発送、ゲーム内の判定ツールを扱いません。賞品がある場合は、主催がこのキットの外で決めた方法を、告知に1行で書きます。
