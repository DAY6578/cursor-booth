# 日程の文面

`日程` チャンネルに貼ってピン留めします。時刻を変えたら、古いピンを外し、新しい文面をピンします。口頭だけで変更しません。

```
【大会名】の日程

日付: 【日付】
受付開始: 【時刻】（日本時間）
試合開始: 【時刻】（日本時間）
終了の目安: 【時刻】（日本時間）

場所: このサーバーのボイスチャンネル
- 集合は「待機」
- 出場は「試合」
- 見るだけの人は「観戦」

ゲーム: 【ゲーム名】
配信: する / しない
配信する場合の範囲: 試合ボイスの音声 / ゲーム画面 / 両方 / 配信しない

遅れる場合: 開始の【分】前までに「欠席連絡」へ書いてください。
無連絡の場合: 当日手順の待ち時間を過ぎたら、不戦とします。

このピンが、時刻の正です。
```

配信が「する」のときは、ルールの切り抜き禁止と矛盾しないように、配信で映る範囲を上の1行に書きます。選手の顔を映す予定が無いなら、その旨も1行足します。
