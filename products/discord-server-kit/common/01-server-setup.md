# サーバーの作り方

新規のDiscordサーバーを作り、このキットの骨組みを載せる手順です。既存サーバーを直す場合は、空のチャンネルで権限を試してから、今あるチャンネルへ移してください。

## 作る

1. Discordのアプリ、またはブラウザ版を開く。
2. 左のサーバー一覧で「＋」を押す。
3. 「サーバーを作成」から、自分で作る（オリジナルの作成、またはそれに相当する項目）を選ぶ。
4. 用途を聞かれたら「自分と友達のため」を選ぶ。コミュニティ機能は、あとから必要なときだけ有効にする。
5. サーバー名を付ける。アイコンを置くなら、自作か、利用してよい画像だけにする。
6. 作成後、自分だけがいる状態で、次のファイルへ進む。

サーバー名とアイコンのルールは `04-naming-rules.md` です。

## そのあとの順番

1. `02-roles-and-permissions.md` のとおり、ロールを上から作る。
2. 選んだパックのチャンネル表で、カテゴリとチャンネルを作る。
3. チャンネルの権限を、パックの表どおりに上書きする。
4. パックの文面を貼り、必要なものだけピン留めする。
5. 別のアカウントで、参加直後の人に見える範囲を確認する。別アカウントが無いときは、ロールを外した友人に見てもらう。
6. 問題がなければ、下の手順でテンプレートを作る。
7. 招待リンクは、パックの公開前チェックが終わってから作る。

## 招待リンク

1. サーバー名をクリックする。
2. 「招待を作成」を選ぶ。
3. リンクの設定で、期限と回数を指定する。最初は7日、回数は必要な人数だけでよい。
4. 期限なし、回数なしのリンクは、公開するサーバーで必要になってから作る。漏れたら無効化して、作り直す。

## サーバーテンプレートを作る

テンプレートは、同じ骨組みのサーバーをもう1つ作るためのDiscord標準機能です。ボットは使いません。

1. チャンネルとロールの作成が終わってから行う。
2. サーバー名をクリックし、「サーバー設定」を開く。
3. 左の一覧から「サーバーテンプレート」を開く。
4. タイトルと説明を入れる。説明に、個人の連絡先や本名を書かない。
5. 「リンクを生成」または「生成」を押す。
6. 出たリンクを、自分の保管場所へコピーする。このキットのファイルには、そのリンクを書き戻さない。
7. プレビューで、チャンネルとロールが入っていることを確認する。
8. 構成を変えたあとは、同じ画面でテンプレートを同期（更新）する。同期しないと、リンクの中身は古いままです。

テンプレートに入らないもの:

- メッセージとピン留め
- メンバーと、その人に付いているロール
- 参加禁止の一覧
- 招待リンク

### 見つからないとき

次の順で探してください。

1. サーバー設定の左の一覧を、最後までスクロールする。
2. サーバー名のメニューに「テンプレート」が無いか見る。
3. それでも無い、または生成が失敗する場合は、テンプレートを使わない。パックのチャンネル表とチェックリストを、手で再現する。
4. 生成の失敗で「上書きが多すぎる」といった表示が出たら、チャンネルごとの権限を減らし、同じ設定はカテゴリ側にまとめてから、もう一度生成する。

テンプレートが使えなくても、このキットの表だけでサーバーは作れます。

## コミュニティ機能（任意）

ファンコミュニティで、参加時にルール同意を出したいときだけ使います。ボットは不要です。大会サーバーでは、必須にしません。

1. サーバー設定で「コミュニティを有効にする」または同じ意味の項目を開く。
2. 画面の条件に従う。ルール用チャンネルと、運営向けチャンネルの指定を求められることが多いです。
3. 有効にしたあと、「安全性設定」または「安全セットアップ」を開く。
4. ダイレクトメッセージと迷惑行為、またはルールの項目から、「ルールに同意するまで発言できない」という意味の設定を有効にする。
5. ルールは、パックのルール文から短い条項を選んで入れる。長い説明は、ルールチャンネル側に残す。

### 見つからないとき

コミュニティ機能が無い、または条件を満たせない場合は、パックの手動確認に切り替えます。

- ファンコミュニティ: `pack-fan/06-membership-checklist.md`
- 大会・カスタム: 参加受付の文面を読み、スタッフがロールを手で付ける

## 作ったあとに確認すること

- サーバー所有者以外のテスト用アカウントで、ルールとお知らせが見える
- そのアカウントは、メンバー用チャンネルに書き込めない
- ロールを付けたあと、パックで許可したチャンネルだけ書き込める
- ボイスチャンネルに、許可していないロールが入らない
- 運営用チャンネルが、一般の参加者から見えない
