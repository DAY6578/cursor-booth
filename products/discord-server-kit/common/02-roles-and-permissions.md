# ロールの階層と権限

権限は、ロールの並びと、チャンネルごとの上書きで決まります。パックの表を付ける前に、このページの操作だけ覚えてください。

## 並び

ロール一覧は、上が強く、下が弱いです。`@everyone` は常に一番下で、削除できません。

サーバー所有者は、ロールが無くても全権限を持ちます。所有者を増やす機能はありません。普段の運営は、所有者の下に「管理者」または「主催」を置いて任せます。

並びの原則:

1. 運営の最上位（管理者、または主催）
2. 運営の補助（モデレーター、またはスタッフ）
3. 通知や参加者のロール（メンバー、お知らせ通知、選手、待機、観戦）
4. `@everyone`

「ロールの管理」を持つ人は、自分より下のロールだけを付与できます。自分と同じ段、自分より上は付与できません。

## 作る

1. サーバー名 → サーバー設定 → ロール。
2. 「ロールを作成」を押す。
3. 名前と色を付ける。名前のルールは `04-naming-rules.md` です。
4. 権限は、選んだパックの表だけをオンにする。表に無い権限はオフのままにする。
5. 保存する。
6. ロール一覧をドラッグして、上の並びにする。

「ロールを別に表示する」は、通知ロールだけオンにしてかまいません。権限の強さとは別です。

## 三つのスイッチ

チャンネル権限には、次の三状態があります。

| 表示 | 意味 |
| --- | --- |
| 斜線（継承） | サーバー全体の権限に従う |
| 緑（許可） | このチャンネルでは許可する |
| 赤（拒否） | このチャンネルでは拒否する |

拒否は許可に勝ちます。同じ人に、許可のロールと拒否のロールが両方あると、拒否になります。

このため、拒否は `@everyone` にだけ付けます。個別のロールには、許可か継承だけを付けます。人を指定した個別の上書きは、例外のときだけにします。

「管理者」という名前の権限（すべての権限を飛ばすスイッチ）は、どのロールにも付けません。付けると、チャンネルの拒否が効かなくなります。サーバー所有者だけが、最初から全権限を持っています。

## 上書きの付け方

1. チャンネル名の横の歯車を開く。カテゴリにも歯車があります。
2. 「権限」を開く。
3. ロールを追加する。
4. パックの表どおりに、許可と拒否を付ける。
5. 保存する。
6. カテゴリを保存したとき、中のチャンネルへ同期するか聞かれたら、同じ設定でよいチャンネルは同期する。違う設定にしたいチャンネルだけ、あとから上書きする。

## サーバー全体の初期値

パックの表は、この初期値から始まっています。先に `@everyone` を絞ってから、上のロールで必要なところだけ許可します。

| 権限 | @everyone |
| --- | --- |
| チャンネルを見る | オン |
| メッセージ履歴を読む | オン |
| メッセージを送信 | オフ |
| スレッドでメッセージを送信 | オフ |
| 公開スレッドの作成 | オフ |
| リアクションの追加 | オフ |
| ファイルを添付 | オフ |
| 埋め込みリンク | オフ |
| 全員へのメンション | オフ |
| 招待を作成 | オフ |
| 接続 | オフ |
| 発言 | オフ |
| ビデオ | オフ |
| 画面共有 | オフ |
| メンバーをキック | オフ |
| メンバーをBAN | オフ |
| メンバーをタイムアウト | オフ |
| メッセージの管理 | オフ |
| チャンネルの管理 | オフ |
| ロールの管理 | オフ |
| サーバー管理 | オフ |
| 監査ログの表示 | オフ |
| 管理者 | オフ |

チャンネルを見るがオンでも、チャンネル側で `@everyone` を拒否すれば、そのチャンネルは隠れます。

## 運営ロールの共通部分

パックで名前は変わりますが、権限の分け方は同じです。

| 権限 | 補助（モデレーター / スタッフ） | 最上位（管理者 / 主催） |
| --- | --- | --- |
| メッセージの管理 | オン | オン |
| メンバーをタイムアウト | オン | オン |
| メンバーをキック | オン | オン |
| メンバーをBAN | オフ | オン |
| メンバーを移動 | オン | オン |
| メンバーをミュート | オン | オン |
| ニックネームの管理 | オン | オン |
| 監査ログの表示 | オン | オン |
| 招待を作成 | オン | オン |
| チャンネルの管理 | オフ | オン |
| ロールの管理 | オフ | オン |
| サーバー管理 | オフ | オン |
| 管理者 | オフ | オフ |

補助ロールにBANとチャンネル削除を付けないのは、初動の事故を最上位に集約するためです。キックまでで足りない事案は、`03-moderation-first-response.md` に沿って最上位へ渡します。

## テスト

1. テスト用の人から、運営ロールを全部外す。
2. ルールが見え、メンバー用チャンネルが見えないことを確認する。
3. 参加者ロールを1つ付ける。
4. パックで許可したチャンネルだけ見え、書け、ボイスに入れることを確認する。
5. 運営ロールを付け、運営チャンネルが見えることを確認する。
6. テストが終わったら、テスト用の人のロールを本番の状態に戻す。

## 見つからないとき

- 権限の名前が表と違うときは、同じ意味の項目を探す。例: 「メンバーを禁止」はBAN、「メンバーを移動」はボイスの移動です。
- 緑と赤のスイッチが無いときは、チェックボックスのオンとオフで、許可と拒否を表します。継承が選べない画面では、オフを継承とみなし、拒否にしたいときだけ明示的に拒否します。
- 迷ったら、その権限はオフのままにして、テスト用アカウントで足りないことだけをオンにします。
