# モデレーションの初動

問題が起きた最初の対応です。公開の場で相手を追い詰めず、記録を残し、権限の範囲だけで動きます。

この手順は法律の助言ではありません。犯罪や、今すぐの危険だと思うときは、運営の対応より先に、その地域の相談窓口や警察へ連絡する判断を優先してください。

## 最初の5分

1. メッセージを消す前に、運営だけが見る場所へ、次の4つを残す。時刻、チャンネル名、相手の表示名、内容の要約。
2. 電話番号、住所、口座、パスワード、本人確認の画像は、要約にも写さない。「個人情報が含まれていた」とだけ書く。
3. 公開チャンネルへの注意は、下の短文を1回だけ貼る。経緯を長く書かない。
4. 同じ内容を、ほかのチャンネルへ転記して呼び出さない。
5. クールダウンが必要ならタイムアウトにする。長さの目安は、10分、60分、24時間。
6. 対応した人の表示名と、削除・タイムアウト・キックのどれをしたかを残す。

公開チャンネルに貼る短文:

```
この話題はここまでにしてください。続きが必要なら、運営が個別に確認します。
```

## 段階

| 段階 | 使うとき | 誰が |
| --- | --- | --- |
| 注意 | 一度きりで、被害が小さい | 補助ロール以上 |
| タイムアウト | その場を止めたい。繰り返しの芽がある | 補助ロール以上 |
| キック | 居続けると荒れるが、再参加の余地はある | 補助ロール以上 |
| BAN | 個人情報の故意の投稿、執拗な嫌がらせ、荒らし、なりすまし | 最上位だけ |

キックした人は、招待リンクがあれば戻れます。戻してほしくないときはBANです。BANの画面で過去メッセージの削除を聞かれたら、荒らしの連投だけ削除します。通常の会話まで消す必要はありません。

## 状況別

| 状況 | 最初の対応 | 次 |
| --- | --- | --- |
| 言い争い | 短文を1回貼る。双方の主張を公開で裁かない | 続くなら双方を10分タイムアウト。運営メモで要点だけ聞く |
| 特定の人への誹謗、差別、嫌がらせ | 該当メッセージを削除する。公開で晒さない | 繰り返すならタイムアウト。さらに続くならキック。執拗なら最上位がBAN |
| 個人情報が書かれた | すぐ削除する。内容を別の場所へコピーしない | 故意、または他人の情報なら最上位がBANを判断する |
| 連投、無関係な招待、同じ文のスパム | タイムアウトにし、連投を削除する | 招待リンクを無効化して作り直す。最上位がBAN |
| なりすまし | その人のロールを外す。表示名を戻すよう伝える | なりすまされた本人が分かるなら、その人のロールも一度確認する。必要ならBAN |
| 運営への侮辱 | ほかのメンバーと同じ基準で扱う | 感情で権限を足さない。判断に迷うなら、もう一人の運営に渡す |

## 残す文面

運営メモに、この型で1件ずつ残します。

```
時刻:
チャンネル:
相手の表示名:
要約:
したこと: 注意 / タイムアウト（長さ） / キック / BAN / 削除のみ
対応した人:
最上位への引き継ぎ: 要る / 要らない
```

## やってはいけないこと

- 証拠を見せるために、問題の文を別チャンネルへ貼り直す
- 個人情報の桁や画像を、注意文のなかで再掲する
- 公開の投票で、キックやBANを決める
- 補助ロールの人に、その場でBAN権限を渡す
- 相手のほかのサーバーや、配信のコメント欄まで追う
- 怒りが残っているうちに、BANの理由を長く公開する

BANやキックの理由を本人へ伝えるときは、短くします。

```
サーバーのルールに反したため、参加を解除しました。
```

詳細の議論は、公開チャンネルでは再開しません。

## 監査ログ

サーバー設定の「監査ログ」で、削除、キック、BAN、ロール変更の履歴を確認できます。見るには、監査ログの権限が必要です。パックの補助ロールと最上位には、この権限を付けています。

表示が無いときは、運営メモの記録を正とします。

## 標準の自動フィルタ（任意）

Discordには、招待リンクの連投や、指定した語を止める標準機能（AutoMod という名前のことが多い）があります。使うなら、サーバー設定からその項目を開き、このサーバーで禁止すると決めたものだけを登録します。

この機能が無くても、上の初動だけで運営できます。外部のボットは追加しません。
