# 命名ルール

サーバー名、チャンネル名、ロール名を、後から見て役割が分かるものにします。雰囲気のための長い呼び名は付けません。

## サーバー

- コミュニティや大会の呼び名を、そのままサーバー名にする。
- 「公式」「公認」は、権利者からその表示を認められていない限り入れない。
- アイコンに、他社や他作品のロゴを使わない。
- 個人の本名、住所、電話番号を名前に入れない。

例:

| 用途 | 名前の例 |
| --- | --- |
| ファンコミュニティ | 【呼び名】の交流 |
| 大会 | 【大会名】 |

## チャンネル

- 短い日本語にする。用途が名前だけで分かるようにする。
- カテゴリも用途で付ける。案内、交流、参加、試合、ボイス、運営。
- 先頭の絵文字は、付けても1つまで。無くてよい。
- 「一般」「雑談2」「雑談3」のように、番号だけで増やさない。増やすときは用途で分ける。
- チャンネルのトピックに、書いてよいことを1行で入れる。
- 大会が終わって不要になったチャンネルは、テンプレートへ同期する前に削除する。

パックのチャンネル名は、各パックのチャンネル表をそのまま使ってください。別名にするときは、表の「用途」を変えないようにします。

## ロール

- 権限が分かる名前にする。メンバー、モデレーター、管理者、主催、スタッフ、選手、待機、観戦、お知らせ通知。
- 色の名前だけ、または「VIP」だけにしない。色は見分け用であり、権限の代わりではない。
- 通知専用ロールは、権限ロールと名前で区別する。例: お知らせ通知。
- 一人の本名をロール名にしない。
- パックに無いロールを増やすときは、共通の並び規則に従い、自分より上の権限を持たせない。

## 表示名

- 参加者の呼び名は、本人が決める。
- 本名の公開を、参加の条件にしない。
- 参加受付で集めてよいのは、サーバー上の表示名と、本人が書いてよい範囲のゲーム内表示名まで。
- なりすまし、または誹謗になる表示名は、ニックネームの管理権限で変更できる。変更した事実を運営メモに残す。

## 文面のなかの置き換え

コピー用の文面にある【　】は、貼る前に必ず置き換えます。

| 記号 | 入れるもの |
| --- | --- |
| 【コミュニティ名】 | サーバーの呼び名 |
| 【大会名】 | その回の大会またはカスタムの名前 |
| 【ゲーム名】 | 主催が使うゲームの名前。このキットは特定のタイトルを指定しない |
| 【日付】 | 開催日 |
| 【時刻】 | 開始時刻。タイムゾーンが混ざるなら「日本時間」と書く |
| 【人数】 | 定員 |
| 【分】 | 欠席連絡の締め切りまでの分数 |

置き換えたあとも、連絡先のメールアドレス、電話番号、自宅の位置は書かないでください。連絡は、このDiscordの指定チャンネルで足ります。
