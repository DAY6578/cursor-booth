# obs-clock

OBSブラウザソース用のデジタル時計。実装ファイルは、環境構築のときに動かしていない。

| 商品 | 場所 | 状態 |
| --- | --- | --- |
| 地獄のデジタル時計 | `地獄のデジタル時計/` | 販売用。テーマは業火、冥府、紅蓮、烙印 |
| 動くデジタル時計 | `ugoku-digital-clock/` | 同系統。テーマはネオン、ミニマル、パステル、モノ |

購入者向け zip に入れるのは、説明書、`デザインを変える.html`、`overlay/` だけである。`販売ページ/` は販売者用で、zip に入れない。

フォルダの移動や統合が必要になったら、店長が `cursor-ready` の Issue にする。それまではこの場所のままにする。

仕様の正本は `docs/product-spec.md`。
