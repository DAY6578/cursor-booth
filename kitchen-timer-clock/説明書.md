# キッチンタイマー時計

OBS のブラウザソースに置く、透過の時計です。見た目はキッチンタイマーの家電です。中央の液晶は、いまの時刻を出します。解凍したあとは、画面の案内だけです。

## 手順

1. この zip を解凍する。
2. `デザインを変える.html` をダブルクリックして、ブラウザで開く。
3. テーマや色を決めて、「OBS用の時計をダウンロード」を押す。
4. OBS でソースの「+」から「ブラウザ」を追加する。
5. 「ローカルファイル」にチェックを入れ、ダウンロードした html ファイルを選ぶ。
6. 幅 720、高さ 800 くらいにする。丸い本体が切れない大きさにしてください。
7. 「非表示時にソースをシャットダウン」にチェックを入れる。

背景が黒や白で残るときだけ、カスタム CSS に次の1行を貼ってください。

```css
body { background-color: rgba(0,0,0,0) !important; }
```

`overlay/` は、見た目を変える前の時計です。色やテーマを変えるときは `デザインを変える.html` を使います。

## 画面でできること

- テーマは雪白、薄荷、朱鈴、胡桃
- 色はカラーピッカーと見本から選ぶ。液晶の数字の色が変わります。筐体の色はテーマのままです
- 24時間と12時間（12時間は午前・午後）
- 秒を出す、出さない
- 日付と曜日（日月火水木金土）を出す、出さない
- 時刻は、このパソコンの時刻、日本時間、またはその他の時差

選んだ内容は、同じブラウザで次に開いたときも残ります。

桁が変わるとき、液晶の線が切り替わります。コロンは液晶らしく点滅します。周りに並んだ 0 から 55 は、キッチンタイマーの目盛りです。針は動かず、時刻は中央の液晶だけが出します。パソコンの「視差効果を減らす」がオンのときは、桁の切り替わりとコロンの点滅は止まります。

保存した時計の背景は透過です。市松模様は、編集画面で透け具合を見るためのもので、保存したファイルには入りません。

カウントダウン、ポモドーロ、アラーム音はありません。現在時刻の時計です。
