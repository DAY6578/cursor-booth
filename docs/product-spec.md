# 商品仕様（現状）

2026-09-22 時点の観察である。このファイルは実装指示ではない。変更は `cursor-ready` の Issue に書いてから行う。

共通:

- OBS のブラウザソースに置く、背景透過のデジタル時計
- 起動は `デザインを変える.html`。テーマと色を決め、OBS用HTMLをダウンロードする
- 時刻は、このパソコン、日本時間、またはその他の時差
- 24時間 / 12時間（午前・午後）、秒、日付と曜日の表示切替
- 「ふわっと動かす」は初期オフ
- 桁が変わるとき数字が転がる。コロンは静かに呼吸する
- 選んだ内容は、同じブラウザで次に開いたとき残る
- OSの「視差効果を減らす」がオンのとき、動きは止まる
- フォントは同梱。ネットワークにはつながない
- 購入者本人の配信と個人利用。再配布、転売、部品としての再販売はしない

- テーマ: 業火、冥府、紅蓮、烙印
- 火の粉がゆっくり上がる
- 購入者向け zip 名: `地獄のデジタル時計.zip`
- zip の中身: `説明書.md`、`デザインを変える.html`、`overlay/`
- `販売ページ/` は販売者用。zip に入れない
- 販売メモ上の初期価格の目安は 480円。価格変更はオーナー承認が必要
