# FAQ

購入者向けの現行手順。変更するときは Issue にする。

## 置き方

1. zip を解凍する。
2. `デザインを変える.html` を開く。
3. 「OBS用の時計をダウンロード」を押す。
4. OBSでブラウザソースを追加し、ローカルファイルにダウンロードした HTML を指定する。
5. 幅 960、高さ 320 くらい。日付を出さないなら高さ 240 でも足りる。
6. 「非表示時にソースをシャットダウン」にチェックを入れる。

## 背景が黒や白で残る

ブラウザソースのカスタム CSS に次を入れる。

```css
body { background-color: rgba(0,0,0,0) !important; }
```

## 光がくすむ（地獄のデジタル時計）

ブラウザソースを右クリックし、「ブレンド方法」の「SRGBオフ」にチェックを入れる。

## 保存した時計の市松模様

編集画面で透け具合を見るためのもの。保存したファイルには入らない。

## 設定が残る

選んだ内容は、同じブラウザで次に開いたとき残る。
